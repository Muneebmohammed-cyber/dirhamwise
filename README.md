# DirhamWise

Personal finance and budget app for the UAE: income & expenses, budgets, credit cards, loans & EMI, savings goals, investments, reports and reminders.

Installable web app (PWA). All data is stored only on the device (localStorage + IndexedDB); nothing is sent to a server. Works offline.

Install: open the site in Safari (iPhone) → Share → Add to Home Screen, or in Chrome (Android) → ⋮ → Install app.
